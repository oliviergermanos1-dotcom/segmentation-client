1 Importer les fichiers Excel

Chargez vos fichiers Excel un par un OU plusieurs a la fois. Chaque nouveau fichier s'ajoute aux precedents (concat + dedup automatique sur JobfileNumber). Pour repartir de zero, cliquez "Vider tout".

3 Agreger par client

N-1 et l'historique sont calcules automatiquement. Cycle de vie = comparaison N vs N-1 vs avant.

Cochez les colonnes utiles pour vos regles de segmentation (ex : ARGOS Type Name, Shipping Type Name, Activity Name). Pour chaque client, on garde la valeur qui revient le plus souvent.

4 Definir les regles de segmentation

Les regles sont sauvegardees automatiquement dans le navigateur. Vous pouvez ajouter / modifier / supprimer une regle a tout moment. Le premier segment qui matche est attribue ; sinon le client recoit Non classe. Reordonnez avec les boutons monter / descendre.
